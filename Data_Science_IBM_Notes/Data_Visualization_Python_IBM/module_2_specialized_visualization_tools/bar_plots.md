## Welcome to Bar Charts. 

### Bar Plots : 

    Unlike a histogram, a bar chart, also known as a bar graph, is a type of plot where the length of each bar is proportional to the value of the item that it represents. It's commonly used to compare the values of a variable at a given point in time. For example, say we want to visualize in a discrete fashion, how immigration from Iceland to Canada looked 1980-2013. One to do that is by building a bar chart where the height of the bar represents the total immigration from Iceland to Canada in a particular year.
